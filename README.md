# SymptomTracker

Tracker 4 Brooke

## Description

SymptomTracker is a personal health tracking application designed to help you monitor and log your daily symptoms, mood, and physical well-being.

## Features

- **Daily Log**: Record daily mood, pain levels, and physical symptoms
- **Mood Tracking**: Rate your mood on a 1-5 scale and select descriptive adjectives
- **Pain Management**: Track pain levels and symptoms
- **Monthly Matrix**: Visualize trends across the month
- **Secure Access**: PIN-protected entries for privacy

## How to Use

1. Open `index.html` in your web browser
2. Enter the PIN code to access your tracker
3. Select the date and log your:
   - Mood scale (1-5)
   - Mood descriptors (Heavy, Gloomy, Hopeless, etc.)
   - Pain scale (1-5)
   - Physical symptoms (Sharp, Dull, Tight, Burning, etc.)
   - Bleeding status (None, Spotting, Light, Heavy)
4. View trends in the Monthly Matrix tab

## Data Storage

All entries are stored locally in your browser using localStorage - no data is sent to any server.
